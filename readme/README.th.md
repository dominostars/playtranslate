## ฟีเจอร์

- **แปลแบบแตะเดียว**: จับภาพหน้าจอเกมและแปลข้อความบนหน้าจอได้ด้วยการแตะเพียงครั้งเดียว
- **โหมดแปลอัตโนมัติ**: แปลให้โดยอัตโนมัติเมื่อบทสนทนาเปลี่ยน ไม่ต้องแตะเลย
- **ค้นหาคำ**: เลื่อนแว่นขยายแบบลอยไปไว้เหนือคำใดก็ได้ เพื่อดูคำจำกัดความจากพจนานุกรมได้ทันที
- **ออฟไลน์**: OCR และการค้นหาคำในพจนานุกรมใช้งานได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต และยังดาวน์โหลดโมเดลออฟไลน์สำหรับการแปลมาใช้ได้ตามต้องการ
- **โหมดฟุริงานะ/พินอิน**: แสดงคำอ่านกำกับไว้เหนือตัวอักษรแบบเรียลไทม์
- **ปุ่มลัด**: ตั้งค่าปุ่มฮาร์ดแวร์ให้กดค้างเพื่อแสดงคำแปลหรือฟุริงานะ เหมาะมากกับเครื่องเล่นเกมพกพาที่มีปุ่มเสริม
- **สองหน้าจอและแยกหน้าจอ**: ใช้งานได้บนทั้งสองจอของอุปกรณ์สองหน้าจออย่าง Ayn Thor หรือใช้ในโหมดแยกหน้าจอของ Android คู่กับเกมที่เปิดแบบหน้าต่าง
- **พื้นที่จับภาพ**: จำกัดการจับภาพไว้เฉพาะกล่องบทสนทนา คำบรรยาย หรือพื้นที่ใดก็ได้ที่กำหนดเอง
- **การอ่านออกเสียงข้อความ**: ให้แอปอ่านข้อความออกเสียงให้ฟัง และเปลี่ยนเสียงเริ่มต้นได้ในการตั้งค่า
- **ส่งออกไปยัง Anki**: บันทึกประโยคลงใน AnkiDroid พร้อมข้อความต้นฉบับ คำแปล รายการคำ คำเป้าหมาย เสียงอ่านออกเสียง และภาพหน้าจอ ทั้งยังบันทึกเสียงเกมใส่ลงในการ์ดได้ด้วย! เลือกประเภทการ์ดได้ และมีค่าที่ตั้งไว้ล่วงหน้าสำหรับสำรับยอดนิยม
- **การผสานรวม Yomitan**: พจนานุกรม Yomitan ผสานรวมเข้ากับแอปได้อย่างราบรื่น ทั้งการเน้นระดับเสียง ป้ายความถี่ ข้อมูลคันจิเพิ่มเติม และคำจำกัดความที่รวมจากหลายพจนานุกรม ซึ่งแสดงได้ทุกที่ (รวมถึงใน Anki) โปรดติดตามการผสานรวมที่ลึกยิ่งขึ้นในอนาคต
- **การแปลด้วยกล้อง**: เล็งกล้องไปที่ข้อความรอบตัวเพื่ออ่านคำแปลแบบเรียลไทม์ หรือถ่ายภาพนิ่งไว้เพื่อแตะคำแล้วค้นหาความหมาย
- **ประวัติข้อความ**: เก็บประโยคที่จับภาพไว้ ปิดอยู่โดยค่าเริ่มต้น

## วิธีติดตั้ง

1. [ดาวน์โหลดเวอร์ชันล่าสุดได้ที่นี่](https://github.com/dominostars/playtranslate/releases/latest)
2. บนอุปกรณ์ Android ของคุณ อนุญาตให้เบราว์เซอร์หรือแอปจัดการไฟล์ติดตั้งแอปที่ไม่รู้จักได้ โดยเปิด **การตั้งค่า → แอป → สิทธิ์เข้าถึงพิเศษของแอป → ติดตั้งแอปที่ไม่รู้จัก** เลือกแอปที่จะใช้เปิดไฟล์ APK แล้วเปิด **อนุญาตการติดตั้งจากแหล่งที่มานี้** นอกจากนี้ เมื่อเปิดไฟล์ APK ครั้งแรก Android ก็จะเสนอให้ไปที่หน้านี้ด้วย
3. เปิดไฟล์ APK แล้วแตะ “ติดตั้ง”
4. เมื่อเปิดแอปครั้งแรก ให้ทำตามขั้นตอนบนหน้าจอเพื่อให้สิทธิ์ที่จำเป็น

### กรณีติดตั้งไม่ได้

ในอุปกรณ์ Android บางรุ่น **Google Play Protect** จะบล็อกไฟล์ APK ที่ติดตั้งจากนอก Play Store และแสดงคำเตือนที่ไม่ชัดเจน เช่น “ไม่ได้ติดตั้งแอป” หรือ “ตรวจพบแอปที่เป็นอันตราย” หากเกิดกรณีนี้ ให้ปิดการสแกนชั่วคราวดังนี้

1. เปิด **Play Store**
2. แตะ **ไอคอนโปรไฟล์** ที่มุมขวาบน
3. แตะ **Play Protect**
4. แตะ **ไอคอนรูปเฟือง** ที่มุมขวาบน
5. ปิด **สแกนแอปด้วย Play Protect**

ติดตั้งไฟล์ APK ให้เสร็จ แล้วเปิด **สแกนแอปด้วย Play Protect** อีกครั้งเพื่อให้สแกนแอปอื่นๆ ต่อไป

### กรณีเปิดการช่วยเหลือพิเศษไม่ได้

ฟีเจอร์ขั้นสูงบางอย่าง (เช่น การกดปุ่มลัดค้างเพื่อแสดงคำแปล) จะขอให้คุณเปิดสิทธิ์การช่วยเหลือพิเศษ ใน Android 13 ขึ้นไป ระบบจะทำให้สวิตช์การช่วยเหลือพิเศษเป็นสีเทาสำหรับแอปทุกแอปที่ติดตั้งจากไฟล์ APK ที่ดาวน์โหลดมา และเมื่อแตะสวิตช์จะมีข้อความ “การตั้งค่าที่จำกัด” แสดงขึ้น หากต้องการปลดบล็อก ให้ทำดังนี้

1. ใน **การตั้งค่า → การช่วยเหลือพิเศษ** ให้เลือก PlayTranslate แล้วแตะสวิตช์สีเทาหนึ่งครั้ง จากนั้นปิดข้อความ “การตั้งค่าที่จำกัด”
2. เปิดหน้า “ข้อมูลแอป”: **การตั้งค่า → แอป → PlayTranslate**
3. แตะเมนู **⋮** แล้วเลือก **อนุญาตการตั้งค่าที่จำกัด** ตัวเลือกนี้จะปรากฏหลังจากทำขั้นตอนที่ 1 แล้วเท่านั้น
4. ยืนยันตัวตนหากระบบขอ จากนั้นกลับไปที่การช่วยเหลือพิเศษแล้วเปิดสวิตช์

## บริการแปลออนไลน์ (ไม่บังคับ)

โดยค่าเริ่มต้น PlayTranslate จะแปลด้วย [Lingva](https://github.com/thedaviddelta/lingva-translate) และเมื่อการแปลออนไลน์ไม่พร้อมใช้งาน จะใช้ ML Kit แปลแบบออฟไลน์เป็นทางเลือกสำรอง หากต้องการคำแปลที่มีคุณภาพสูงขึ้น ให้ใส่คีย์ API ของบริการใดก็ได้ด้านล่างนี้ที่ **การตั้งค่า → บริการแปล** จะเพิ่มกี่บริการก็ได้ แต่ละบริการจะแสดงแยกกันในรายการ คุณจึงตั้งค่าไว้หลายบริการ แล้วจัดลำดับใหม่เพื่อเลือกว่าบริการใดจะแปลก่อนได้

- **DeepL**: มีแผนฟรี สมัครได้ที่ [deepl.com/en/pro#developer](https://www.deepl.com/en/pro#developer)
- **OpenAI**: รับคีย์ได้ที่ [platform.openai.com](https://platform.openai.com/api-keys) และเลือกโมเดลได้ในแอป
- **Gemini**: รับคีย์ได้ที่ [aistudio.google.com](https://aistudio.google.com/app/apikey) และเลือกโมเดลได้ในแอป
- **DeepSeek**: รับคีย์ได้ที่ [platform.deepseek.com](https://platform.deepseek.com/api_keys) และเลือกโมเดลได้ในแอป
- **Mistral**: รับคีย์ได้ที่ [console.mistral.ai](https://console.mistral.ai/api-keys) และเลือกโมเดลได้ในแอป
- **Groq**: รับคีย์ได้ที่ [console.groq.com](https://console.groq.com/keys) และเลือกโมเดลได้ในแอป
- **OpenRouter**: รับคีย์ได้ที่ [openrouter.ai](https://openrouter.ai/keys) และเลือกโมเดลได้ในแอป
- **Claude**: รับคีย์ได้ที่ [platform.claude.com](https://platform.claude.com/settings/keys) และเลือกโมเดลได้ในแอป
- **กำหนดเอง**: เซิร์ฟเวอร์อื่นใดก็ได้ที่เข้ากันได้กับ OpenAI โดยป้อน URL เซิร์ฟเวอร์ของคุณในช่อง “URL ที่กำหนดเอง”
