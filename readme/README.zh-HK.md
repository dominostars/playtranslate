一款 Android 即時翻譯與語言學習應用程式，適用於遊戲、視覺小說、漫畫以及螢幕上的任何其他文字。支援 26 種遊戲語言，可翻譯成 59 種語言！

[按此下載最新版本](https://github.com/dominostars/playtranslate/releases/latest)

如需回報問題、取得協助或提出需求，歡迎加入 [Discord 伺服器](https://discord.gg/DVCj6p7MUC)

[在 Persona 3 Reload 中使用 PlayTranslate](https://github.com/user-attachments/assets/e89c2c6e-92f3-41d2-8e51-5483beaca612)

## 功能

- **一鍵翻譯**：點按一次，即可擷取遊戲畫面並翻譯其中的文字
- **自動翻譯**：對話一變就自動翻譯，無需點按
- **詞語查詢**：把懸浮放大鏡移到任意詞語上，立即顯示詞典釋義
- **離線使用**：OCR 和詞典查詢無需網絡連線，還可以另行下載離線翻譯模型
- **振假名／拼音模式**：在漢字上方即時顯示讀音提示
- **快捷鍵**：把一個實體按鍵設為長按預覽翻譯或振假名，特別適合設有專用按鍵的掌機
- **雙螢幕與分割螢幕**：在 Ayn Thor 等雙螢幕裝置上可同時使用兩個螢幕，也能在 Android 分割螢幕模式下，與在視窗中執行的遊戲並排使用
- **擷取區域**：只擷取對話框、字幕或任意自訂區域
- **文字轉語音**：把文字朗讀出來。可以在設定中更改預設語音。
- **匯出到 Anki**：把句子儲存到 AnkiDroid，包含原文、譯文、詞語清單、目標詞語、朗讀音訊和截圖。甚至還能錄製遊戲音訊一併儲存！支援選擇卡片類型，並為熱門牌組內置現成設定。
- **Yomitan 整合**：可無縫整合 Yomitan 詞典，支援音高重音、詞頻標籤和漢字補充資訊，合併後的詞條釋義隨處可用（包括 Anki）。日後還會有更深入的整合。
- **相機翻譯**：用相機對準現實中的文字，就能即時閱讀；也可以拍攝快照，再點按其中的詞語查詢。
- **文字歷史記錄**：保留擷取到的句子。預設關閉。

## 安裝方法

1. [按此下載最新版本](https://github.com/dominostars/playtranslate/releases/latest)
2. 在 Android 裝置上允許你的瀏覽器或檔案管理器安裝不明應用程式：開啟**設定 → 應用程式 → 特別應用程式存取權 → 安裝不明應用程式**，選擇該應用程式，然後開啟**允許此來源的應用程式**。首次開啟 APK 時，Android 也會提示你直接前往該設定
3. 開啟 APK 檔案，點按「安裝」
4. 首次啟動時，按照引導步驟授予所需的權限

### 無法安裝？

在部分 Android 裝置上，**Google Play 安全防護**會攔截側載的 APK，並顯示含糊的「未安裝應用程式」或「有害的應用程式」警告。遇到這種情況時，可以暫時關閉掃描：

1. 開啟 **Play 商店**
2. 點按右上角的**個人資料圖示**
3. 點按 **Play 安全防護**
4. 點按右上角的**設定圖示**（齒輪）
5. 關閉**使用 Play 安全防護掃描應用程式**

裝好 APK 後，記得重新開啟 Play 安全防護，讓它繼續掃描你的其他應用程式。

### 無法開啟無障礙權限？

部分進階功能（例如快捷鍵長按預覽）會提示你開啟無障礙權限。有些 Android 裝置製造商預設不允許側載的應用程式取得無障礙權限，設定中的開關可能顯示為灰色，或出現「受限設定」提示。解除限制的方法：

1. 開啟**設定 → 應用程式 → PlayTranslate**
2. 點按右上角的三點（**⋮**）按鈕
3. 點按**允許受限設定**
4. 按提示完成身份驗證

現在就可以為 PlayTranslate 開啟無障礙權限了。

## 可選：線上翻譯服務

預設使用 [Lingva](https://github.com/thedaviddelta/lingva-translate) 進行翻譯；線上翻譯不可用時，便以 ML Kit 作為離線後備方案。如想獲得更高質素的翻譯，可以在**設定 → 翻譯服務**中為以下任意服務填入 API 金鑰。服務數量不限，每項服務在清單中單獨列出，你可以同時設定多項，再調整次序，決定優先由哪一項翻譯：

- **DeepL**：提供免費方案，前往 [deepl.com/en/pro#developer](https://www.deepl.com/en/pro#developer) 申請
- **OpenAI**：[platform.openai.com](https://platform.openai.com/api-keys)，可在應用程式內選擇模型
- **Gemini**：[aistudio.google.com](https://aistudio.google.com/app/apikey)，可在應用程式內選擇模型
- **DeepSeek**：[platform.deepseek.com](https://platform.deepseek.com/api_keys)，可在應用程式內選擇模型
- **Mistral**：[console.mistral.ai](https://console.mistral.ai/api-keys)，可在應用程式內選擇模型
- **Groq**：[console.groq.com](https://console.groq.com/keys)，可在應用程式內選擇模型
- **OpenRouter**：[openrouter.ai](https://openrouter.ai/keys)，可在應用程式內選擇模型
- **Claude**：[platform.claude.com](https://platform.claude.com/settings/keys)，可在應用程式內選擇模型
- **自訂**：任何其他兼容 OpenAI 的端點，填入你自己的後端 URL 即可

## 可選：Anki 抽認卡

安裝 [AnkiDroid](https://play.google.com/store/apps/details?id=com.ichi2.anki)，並在設定中授予 PlayTranslate 存取權限，即可把卡片直接匯出到你的牌組。
