Приложение для Android, которое в реальном времени переводит игры, визуальные новеллы, мангу и любой другой текст на экране, и помогает учить языки. Поддерживает 26 языков игры и 59 языков перевода!

[Нажмите здесь, чтобы скачать последнюю версию](https://github.com/dominostars/playtranslate/releases/latest)

Чтобы сообщить о проблеме, получить помощь или оставить пожелание, присоединяйтесь к нашему [серверу Discord](https://discord.gg/DVCj6p7MUC).

## Возможности

- **Перевод в одно касание**: захватите экран игры и переведите текст на нём одним касанием.
- **Автоперевод**: текст переводится автоматически по ходу диалога, нажимать ничего не нужно.
- **Поиск слов**: наведите плавающую лупу на любое слово, и сразу появится его определение из словаря.
- **Работа офлайн**: распознавание текста (OCR) и поиск по словарю работают без подключения к интернету, а для перевода можно дополнительно скачать офлайн-модели.
- **Режим фуриганы и пиньиня**: над иероглифами в реальном времени показывается их чтение.
- **Горячие клавиши**: назначьте физическую клавишу, при удержании которой на экране показывается перевод или фуригана. Удобно на портативных консолях с отдельными кнопками.
- **Два экрана и разделение экрана**: работает на обоих экранах устройств с двумя дисплеями, например Ayn Thor, а также в режиме разделения экрана Android рядом с игрой, запущенной в окне.
- **Области захвата**: захватывайте только диалоговое окно, субтитры или любую другую выбранную вами область.
- **Синтез речи**: приложение может прочитать текст вслух. Голос по умолчанию можно сменить в настройках.
- **Экспорт в Anki**: сохраняйте предложения в AnkiDroid вместе с исходным текстом, переводом, списком слов, целевыми словами, озвучкой через синтез речи и снимком экрана. Можно даже записать звук игры и добавить его на карточку! Можно выбрать тип карточки, а для популярных колод есть готовые пресеты.
- **Интеграция с Yomitan**: словари Yomitan органично встраиваются в приложение — тональное ударение, метки частотности, подробные сведения о кандзи и объединённые определения слов доступны повсюду (в том числе в Anki). В будущем интеграция станет ещё глубже.
- **Перевод с камеры**: наведите камеру на текст вокруг себя и читайте перевод в реальном времени или сделайте снимок, чтобы нажимать на слова и смотреть их значения.
- **История текста**: журнал захваченных предложений. По умолчанию выключена.

## Установка

1. [Нажмите здесь, чтобы скачать последнюю версию](https://github.com/dominostars/playtranslate/releases/latest)
2. На устройстве Android разрешите браузеру или файловому менеджеру устанавливать неизвестные приложения: откройте **Настройки → Приложения → Специальный доступ → Установка неизвестных приложений**, выберите нужное приложение и включите параметр **Разрешить установку из этого источника**. Android также сам предложит перейти туда, когда вы впервые откроете APK
3. Откройте APK-файл и нажмите «Установить»
4. При первом запуске пройдите начальную настройку и предоставьте необходимые разрешения

### Не устанавливается?

На некоторых устройствах Android **Google Play Защита** блокирует APK, установленные не из Google Play, и выдаёт невнятное предупреждение вроде «Приложение не установлено» или сообщение о вредоносном приложении. В этом случае временно отключите проверку:

1. Откройте **Google Play**
2. Нажмите на **значок профиля** (в правом верхнем углу)
3. Выберите **Play Защита**
4. Нажмите на **значок шестерёнки** (в правом верхнем углу)
5. Отключите параметр **Проверять приложения с помощью Play Защиты**

Установите APK, а затем снова включите Play Защиту, чтобы она и дальше проверяла остальные приложения.

### Не удаётся включить специальные возможности?

Для некоторых расширенных функций (например, предпросмотра при удержании горячей клавиши) приложение попросит включить разрешение на специальные возможности. Начиная с Android 13 система делает переключатель специальных возможностей серым и неактивным для любого приложения, установленного из скачанного APK-файла, а при нажатии на переключатель появляется сообщение «Настройки с ограниченным доступом». Чтобы снять блокировку:

1. В разделе **Настройки → Специальные возможности** выберите PlayTranslate и один раз нажмите на неактивный переключатель. Закройте сообщение «Настройки с ограниченным доступом».
2. Откройте страницу «О приложении»: **Настройки → Приложения → PlayTranslate**.
3. Нажмите на меню **⋮** и выберите **Разрешить доступ к настройкам**. Этот пункт появляется только после шага 1.
4. Пройдите аутентификацию, если появится запрос, затем вернитесь в раздел специальных возможностей и включите переключатель.

## Дополнительно: онлайн-сервисы перевода

По умолчанию для перевода используется [Lingva](https://github.com/thedaviddelta/lingva-translate), а когда онлайн-перевод недоступен, запасным вариантом служит офлайн-перевод ML Kit. Для более качественного перевода можно добавить API-ключ любого из сервисов ниже в разделе **Настройки → Сервисы перевода**. Добавляйте сколько угодно: каждый сервис — отдельная строка в списке, так что можно настроить несколько и расставить их по порядку, чтобы выбрать, какой из них переводит первым:

- **DeepL**: бесплатный тариф на [deepl.com/en/pro#developer](https://www.deepl.com/en/pro#developer)
- **OpenAI**: [platform.openai.com](https://platform.openai.com/api-keys) — модель выбирается прямо в приложении
- **Gemini**: [aistudio.google.com](https://aistudio.google.com/app/apikey) — модель выбирается прямо в приложении
- **DeepSeek**: [platform.deepseek.com](https://platform.deepseek.com/api_keys) — модель выбирается прямо в приложении
- **Mistral**: [console.mistral.ai](https://console.mistral.ai/api-keys) — модель выбирается прямо в приложении
- **Groq**: [console.groq.com](https://console.groq.com/keys) — модель выбирается прямо в приложении
- **OpenRouter**: [openrouter.ai](https://openrouter.ai/keys) — модель выбирается прямо в приложении
- **Claude**: [platform.claude.com](https://platform.claude.com/settings/keys) — модель выбирается прямо в приложении
- **Свой**: любой другой сервис с API, совместимым с OpenAI, — укажите URL вашего сервера
